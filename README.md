# Notes API

FastAPI-сервис для Модуля 5 демоэкзамена (09.02.07): отдаёт список заметок, предварительно
обработанных перед отправкой клиенту (см. `Прил_5_ОЗ_КИМ_09.02.07-5-2027`).

Источник данных — простой JSON-файл `notes.json` (без базы данных, без SQL).

## Запуск

```bash
python3 -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

На Windows, если `pip`/`uvicorn` не распознаются напрямую, используй Python Launcher:
`py -m pip install -r requirements.txt`, `py -m uvicorn app.main:app --port 8000`.

## Эндпоинт

`GET /notes` (алиас `GET /api/notes`)

Необязательный параметр `id_user` (целое число) — если передан и не является числом, возвращает `400`.

Пример ответа:

```json
[
  {
    "id": "00001",
    "title_user": "Конференция ИТ - user25",
    "content": "Обсуждение планов на 2027 год",
    "formatted_date": "15.03.2027"
  }
]
```

## HTTP-статусы

| Ситуация | Статус | Тело ответа |
|---|---|---|
| Успешный запрос | 200 | список заметок |
| Данных нет (`notes.json` содержит `[]`) | 200 | `[]` |
| Некорректный параметр (`id_user` не число) | 400 | `{"error": "..."}` |
| Файл `notes.json` не найден | 500 | `{"error": "Файл с заметками не найден"}` |

## Как поменять данные

Отредактировать `notes.json` — сервер перезапускать не нужно, он читает файл заново
при каждом запросе.
