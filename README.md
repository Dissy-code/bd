# Notes API

FastAPI-сервис для Модуля 5 демоэкзамена (09.02.07): отдаёт список заметок, предварительно
обработанных перед отправкой клиенту (см. `Прил_5_ОЗ_КИМ_09.02.07-5-2027`).

## Запуск

```bash
python3 -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --port 8000
```

База SQLite (`notes.db`) создаётся и заполняется тестовыми данными автоматически при первом запуске.

## Эндпоинт

`GET /notes` (алиас `GET /api/notes`)

Необязательный параметр `id_user` (целое число) — фильтр по пользователю.

Пример ответа:

```json
[
  {
    "id": "00001",
    "title_user": "Конференция ИТ - user25",
    "content": "Обсуждение планов на 2027 год",
    "formatted_date": "15.03.2027"
  }
]
```

## HTTP-статусы

| Ситуация | Статус | Тело ответа |
|---|---|---|
| Успешный запрос | 200 | список заметок |
| Данных нет | 200 | `[]` |
| Некорректный параметр (`id_user` не число) | 400 | `{"error": "..."}` |
| Внутренняя ошибка (симулируется `?crash=1`) | 500 | `{"error": "Ошибка подключения к базе данных"}` |

## Тесты
