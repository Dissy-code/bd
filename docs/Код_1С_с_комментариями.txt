КОД МОДУЛЯ ФОРМЫ "СИНХРОНИЗАЦИЯ ЗАМЕТОК" — С КОММЕНТАРИЕМ К КАЖДОЙ СТРОКЕ


====================================================================
ПРОЦЕДУРА 1: ПриСозданииНаСервере
====================================================================
Срабатывает один раз — когда форма открывается. Задача: подставить
значения по умолчанию в поля Сервер/Порт/Путь, если они ещё пустые.

&НаСервере
    -> Директива компиляции: эта процедура выполняется НА СЕРВЕРЕ 1С
       (не на компьютере пользователя). Нужно, т.к. дальше будет сетевой
       запрос — такие вещи 1С разрешает делать только серверному коду.

Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)
    -> Заголовок процедуры. "Отказ" и "СтандартнаяОбработка" — служебные
       параметры, которые 1С передаёт автоматически при вызове этого
       системного события формы (мы их тут не используем, но убрать
       нельзя — иначе 1С не поймёт, что это обработчик нужного события).

    Если Не ЗначениеЗаполнено(Объект.Сервер) Тогда
        -> Проверка: если поле "Сервер" ещё не заполнено (пустая строка).
           "Объект" — это сама обработка (её реквизиты, видимые на форме).

        Объект.Сервер = "127.0.0.1";
        -> Если было пусто — подставляем адрес локального компьютера
           (127.0.0.1 = "сам я", то есть сервер, запущенный на этой же
           машине, где открыта 1С).

    КонецЕсли;
    -> Закрывает условие "Если".

    Если Объект.Порт = 0 Тогда
        -> У числового поля по умолчанию значение 0 (а не пустая строка,
           как у текста) — поэтому проверка именно на "= 0".

        Объект.Порт = 8000;
        -> Подставляем порт 8000 — именно на нём слушает наш Python-сервер
           (uvicorn).

    КонецЕсли;

    Если Не ЗначениеЗаполнено(Объект.Путь) Тогда
        Объект.Путь = "/notes";
        -> Подставляем путь запроса — конечный адрес на сервере, куда
           будет направлен запрос: http://127.0.0.1:8000/notes

    КонецЕсли;

КонецПроцедуры
    -> Конец процедуры.


====================================================================
ПРОЦЕДУРА 2: СинхронизироватьНаСервере
====================================================================
Главная логика. Выполняется при нажатии кнопки "Синхронизировать".
Делает HTTP-запрос к Python-серверу, разбирает ответ, пишет данные
в справочник "Заметки".

&НаСервере
    -> Опять серверный код — сетевые запросы и запись в базу данных
       в 1С разрешены только на сервере.

Процедура СинхронизироватьНаСервере()
    -> Заголовок процедуры, без параметров.

    Т0 = ТекущаяДата();
    -> Запоминаем текущее время (с точностью до секунды) — точка отсчёта
       для замера, сколько времени занимает каждый этап синхронизации.

    Защищенное = (Объект.Порт = 443);
    -> Переменная "Защищенное" станет Истина, если порт равен 443
       (стандартный порт для HTTPS), иначе — Ложь. Для нашего локального
       сервера (порт 8000) это всегда Ложь — то есть обычный HTTP,
       без шифрования (оно тут и не нужно, трафик не выходит за пределы
       компьютера).

    Соединение = Новый HTTPСоединение(Объект.Сервер, Объект.Порт,,,,, Защищенное);
    -> Создаём объект "HTTP-соединение" — это как открыть браузер и
       ввести адрес сервера. Параметры по порядку: адрес сервера, порт,
       (три пустых параметра — логин/пароль/прокси, нам не нужны),
       последний параметр — нужно ли шифрованное (HTTPS) соединение.

    Т1 = ТекущаяДата();
    -> Вторая отметка времени — после того, как соединение создано
       (но запрос ещё не отправлен).

    Ответ = Соединение.Получить(Новый HTTPЗапрос(Объект.Путь));
    -> Собственно сам запрос: "HTTPЗапрос(Объект.Путь)" создаёт GET-запрос
       на конкретный адрес (например "/notes"), а ".Получить(...)"
       отправляет его и ЖДЁТ ответа от сервера. Результат (тело ответа,
       код статуса и т.д.) сохраняется в переменную "Ответ".
       Именно эта строка — "поход в интернет/в сеть", она может занимать
       заметное время, если сервер отвечает медленно или недоступен.

    Т2 = ТекущаяДата();
    -> Третья отметка времени — сразу после получения ответа от сервера.

    МассивЗаметок = ПрочитатьЗначениеJSON(Ответ.ПолучитьТелоКакСтроку());
    -> "Ответ.ПолучитьТелоКакСтроку()" достаёт тело HTTP-ответа как обычный
       текст (это и есть тот самый JSON, который присылает Python).
       "ПрочитатьЗначениеJSON(...)" разбирает этот текст и превращает его
       в настоящие данные 1С: JSON-массив "[...]" становится 1С-Массивом,
       а каждый JSON-объект "{...}" внутри — 1С-Структурой с полями.

    Т3 = ТекущаяДата();
    -> Четвёртая отметка времени — после разбора JSON (до начала записи
       в базу).

    Для Каждого Заметка Из МассивЗаметок Цикл
        -> Начинаем перебирать по одному элементу массива. На каждом шаге
           цикла переменная "Заметка" содержит очередную структуру
           (одну заметку из присланного списка).

        Код = Заметка.id;
        -> Достаём поле "id" из структуры (обращение через точку).
           Именно так в JSON было записано "id": "00001" — значение
           "00001" попадает в переменную "Код".

        ЗаголовокПользователь = Заметка.title_user;
        -> Аналогично — достаём поле "title_user" (уже готовая строка
           вида "Конференция ИТ - user25", собранная на стороне Python).

        Содержание = Заметка.content;
        -> Достаём поле "content" — текст самой заметки.

        Ссылка = Справочники.Заметки.НайтиПоКоду(Код);
        -> Ищем в справочнике "Заметки" элемент с таким же кодом, какой
           пришёл из JSON. Если такой элемент уже существует (была
           предыдущая синхронизация) — найдём именно его.

        Если Ссылка.Пустая() Тогда
            -> Проверка: "Ссылка.Пустая()" истинна, если поиск ничего
               не нашёл (элемента с таким кодом ещё нет в базе).

            Элемент = Справочники.Заметки.СоздатьЭлемент();
            -> Создаём совершенно новый, ещё не сохранённый элемент
               справочника.

            Элемент.Код = Код;
            -> Присваиваем ему тот самый код, что пришёл из JSON (иначе
               1С сам присвоил бы автоматический номер по порядку).

        Иначе
            -> Если элемент с таким кодом уже найден —

            Элемент = Ссылка.ПолучитьОбъект();
            -> Превращаем "ссылку" (лёгкий указатель на запись) в полный
               редактируемый "объект" этой же самой записи — только
               через объект можно менять и сохранять данные.

        КонецЕсли;

        Элемент.Наименование = ЗаголовокПользователь;
        -> Записываем в стандартное поле "Наименование" (видно в списке
           справочника как основной текст) значение title_user.

        Элемент.Содержание = Содержание;
        -> Записываем в наше собственное поле "Содержание" текст заметки.

        Элемент.Записать();
        -> Физически сохраняем элемент в базу данных (и новый, и
           обновлённый — команда одна и та же). До этой строки все
           изменения существовали только в оперативной памяти.

    КонецЦикла;
    -> Конец перебора — переходим к следующему элементу массива, пока
       не закончатся все элементы.

    Т4 = ТекущаяДата();
    -> Пятая, последняя отметка времени — уже после того, как все
       заметки записаны в базу.

    Сообщить("Синхронизация завершена. Создание соединения: "
        + (Т1 - Т0) + " сек, HTTP-запрос: " + (Т2 - Т1)
        + " сек, Разбор JSON: " + (Т3 - Т2) + " сек, Запись в БД: " + (Т4 - Т3) + " сек");
    -> Выводим итоговое сообщение пользователю (в панель "Сообщения" внизу
       экрана). Вычитание дат друг из друга в 1С даёт разницу В СЕКУНДАХ —
       так эта строка показывает, сколько секунд заняла КАЖДАЯ из четырёх
       фаз синхронизации (это диагностический вывод, в "боевом" коде его
       можно убрать или заменить на более короткое сообщение).

КонецПроцедуры
    -> Конец процедуры СинхронизироватьНаСервере.


====================================================================
ПРОЦЕДУРА 3: Синхронизировать
====================================================================
Это обработчик самой кнопки на форме.

&НаКлиенте
    -> Выполняется НА КЛИЕНТЕ (на компьютере пользователя) — потому что
       именно клиентский код реагирует на нажатия кнопок в интерфейсе.

Процедура Синхронизировать(Команда)
    -> Заголовок. "Команда" — служебный параметр (какая именно команда
       вызвала процедуру), 1С передаёт его автоматически, мы его тут
       не используем.

    СинхронизироватьНаСервере();
    -> Единственная строка: клиент просто вызывает серверную процедуру
       (ту, что описана выше). Сам клиент ничего не делает — вся работа
       (запрос, разбор, запись) происходит на сервере, клиент только
       инициирует её нажатием кнопки.

КонецПроцедуры
    -> Конец процедуры (и всего файла модуля).
