# Документация: создание и запуск API (Python) + синхронизация в 1С

Полное описание, как **создать с нуля** и **поднять** обе части системы:
локальный API на Python и обработку синхронизации в 1С, которая к нему
обращается. Это рабочая, проверенная схема.

## Общая схема

```
notes.json (файл с данными, /home/dissy/1cc/notes.json)
       |
       |  читает
       v
app.py — Python-процесс (uvicorn + FastAPI)
       |
       |  слушает порт 8000 на 127.0.0.1
       v
http://127.0.0.1:8000/notes
       |
       |  HTTP GET-запрос
       v
1С — обработка "Синхронизация заметок" (кнопка "Синхронизировать")
       |
       |  пишет результат
       v
Справочник "Заметки" внутри базы 1С
```

# ЧАСТЬ 1. Создание и запуск API на Python

## 1.1. Создать окружение

```bash
mkdir notes_api && cd notes_api
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install fastapi "uvicorn[standard]"
```

## 1.2. Подготовить данные

Файл `notes.json` — обычный JSON-массив объектов:

```json
[
  {
    "id": "00001",
    "title_user": "Конференция ИТ - user25",
    "content": "Обсуждение планов на 2027 год",
    "formatted_date": "15.03.2027"
  }
]
```

Поля: `id` (код), `title_user` (заголовок + логин через дефис), `content`
(текст заметки), `formatted_date` (дата в формате ДД.ММ.ГГГГ).

## 1.3. Код сервера (`app/main.py`)

```python
import json
from typing import Optional

from fastapi import FastAPI, Query
from fastapi.responses import JSONResponse

app = FastAPI(title="Notes API")

NOTES_FILE = "/home/dissy/1cc/notes.json"


@app.get("/notes")
@app.get("/api/notes")
def get_notes(id_user: Optional[str] = Query(default=None)):
    if id_user is not None:
        try:
            int(id_user)
        except ValueError:
            return JSONResponse(
                status_code=400,
                content={"error": "Параметр id_user должен быть целым числом"},
            )

    try:
        with open(NOTES_FILE, "r", encoding="utf-8") as f:
            return json.load(f)
    except FileNotFoundError:
        return JSONResponse(status_code=500, content={"error": "Файл с заметками не найден"})
```

Разбор:
- `@app.get("/notes")` — декоратор: GET-запрос на `/notes` вызывает `get_notes()`.
- `id_user` — необязательный параметр запроса; если передан и не число — `400`.
- **Обработка `200`** — вот эта строка:
  ```python
  return json.load(f)
  ```
  Явного `JSONResponse(status_code=200, ...)` здесь нет — и не нужен. Если
  функция просто `return`-ит значение без указания статуса, FastAPI **сам**
  подставляет код `200` (это поведение по умолчанию — "успех"). Это
  отличается от `400`/`500`, где статус указан явно через `JSONResponse(...)`,
  потому что это неуспешные случаи, и код нужно задать вручную.
- Пустой массив в файле → `200` с телом `[]` само собой (ничего отдельно
  обрабатывать не нужно, т.к. `json.load` просто вернёт пустой список).
- Файла нет → `500` с понятным сообщением вместо падения.

## 1.4. Запустить сервер ("поднять" API)

```bash
cd notes_api
source venv/bin/activate
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Окно с этой командой должно оставаться открытым — пока оно работает, API
доступен. Закрыл окно — сервер остановлен.

**На Windows**, если `pip`/`uvicorn` не распознаются напрямую — используй
Python Launcher:

```cmd
py -m pip install fastapi uvicorn
py -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

## 1.5. Проверить, что сервер поднялся

```bash
curl http://127.0.0.1:8000/notes                       # 200, список заметок
curl "http://127.0.0.1:8000/notes?id_user=abc"         # 400, ошибка параметра
mv notes.json notes.json.bak && curl http://127.0.0.1:8000/notes && mv notes.json.bak notes.json
                                                         # 500, файл "потерялся"
```

Все три кода (`200`/`400`/`500`) проверены и работают.

# ЧАСТЬ 2. Создание и запуск обработки в 1С

## 2.1. Открыть Конфигуратор, создать справочник "Заметки"

1. Запустить 1С в режиме **Конфигуратор**.
2. Дерево конфигурации → правой кнопкой на **"Справочники"** → **Добавить**.
3. Имя: `Заметки`. Длина кода — `20` (символьный), длина наименования — `150`.
4. Добавить реквизиты:
   - `Содержание` — строка, неограниченная длина, многострочное.
   - `ДатаЗаметки` — дата (можно не использовать, если не нужна точная дата).
5. Сохранить (Ctrl+S).

## 2.2. Создать обработку "СинхронизацияЗаметок"

1. Правой кнопкой на **"Обработки"** → **Добавить**.
2. Имя: `СинхронизацияЗаметок`.
3. Добавить реквизиты объекта (для полей ввода на форме):
   - `Сервер` — строка (100 символов).
   - `Порт` — число (целое, без дробной части).
   - `Путь` — строка (200 символов).
4. Добавить форму: правой кнопкой на **"Формы"** → **Добавить** → оставить
   имя по умолчанию `Форма`.

## 2.3. Разместить элементы на форме

Открыть форму в конструкторе, перетащить на неё поля `Сервер`, `Порт`, `Путь`
(из реквизитов объекта) и кнопку. У кнопки задать команду, которая вызывает
процедуру `Синхронизировать` (см. код ниже).

## 2.4. Код модуля формы

```bsl
&НаСервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)
	Если Не ЗначениеЗаполнено(Объект.Сервер) Тогда
		Объект.Сервер = "127.0.0.1";
	КонецЕсли;
	Если Объект.Порт = 0 Тогда
		Объект.Порт = 8000;
	КонецЕсли;
	Если Не ЗначениеЗаполнено(Объект.Путь) Тогда
		Объект.Путь = "/notes";
	КонецЕсли;
КонецПроцедуры

&НаСервере
Процедура СинхронизироватьНаСервере()
	// 1. Подключение и HTTP-запрос
	Попытка
		Защищенное = (Объект.Порт = 443);
		Соединение = Новый HTTPСоединение(Объект.Сервер, Объект.Порт,,,,, Защищенное);
		Ответ = Соединение.Получить(Новый HTTPЗапрос(Объект.Путь));
	Исключение
		Сообщить("Ошибка подключения к API (" + Объект.Сервер + ":" + Объект.Порт
			+ "): " + ОписаниеОшибки() + ". Проверь, что сервер запущен.");
		Возврат;
	КонецПопытки;

	// 2. Проверка HTTP-статуса (400 / 500 от API)
	Если Ответ.КодСостояния = 400 Тогда
		Сообщить("API вернул 400 (некорректный запрос): " + Ответ.ПолучитьТелоКакСтроку());
		Возврат;
	ИначеЕсли Ответ.КодСостояния = 500 Тогда
		Сообщить("API вернул 500 (внутренняя ошибка сервера): " + Ответ.ПолучитьТелоКакСтроку());
		Возврат;
	ИначеЕсли Ответ.КодСостояния <> 200 Тогда
		Сообщить("API вернул неожиданный код: " + Ответ.КодСостояния
			+ ". Тело ответа: " + Ответ.ПолучитьТелоКакСтроку());
		Возврат;
	КонецЕсли;

	// 3. Разбор JSON
	Попытка
		МассивЗаметок = ПрочитатьЗначениеJSON(Ответ.ПолучитьТелоКакСтроку());
	Исключение
		Сообщить("Ответ API не является корректным JSON: " + ОписаниеОшибки());
		Возврат;
	КонецПопытки;

	Если ТипЗнч(МассивЗаметок) <> Тип("Массив") Тогда
		Сообщить("Ожидался массив заметок, но API вернул другой формат данных. "
			+ "Проверь поле ""Путь"" — возможно, указан неверный адрес.");
		Возврат;
	КонецЕсли;

	Если МассивЗаметок.Количество() = 0 Тогда
		Сообщить("Данных нет — API вернул пустой список. Это не ошибка.");
		Возврат;
	КонецЕсли;

	// 4. Запись в справочник
	КоличествоЗагружено = 0;
	Для Каждого Заметка Из МассивЗаметок Цикл
		Попытка
			Код = Заметка.id;
			ЗаголовокПользователь = Заметка.title_user;
			Содержание = Заметка.content;

			Ссылка = Справочники.Заметки.НайтиПоКоду(Код);
			Если Ссылка.Пустая() Тогда
				Элемент = Справочники.Заметки.СоздатьЭлемент();
				Элемент.Код = Код;
			Иначе
				Элемент = Ссылка.ПолучитьОбъект();
			КонецЕсли;
			Элемент.Наименование = ЗаголовокПользователь;
			Элемент.Содержание = Содержание;
			Элемент.Записать();
			КоличествоЗагружено = КоличествоЗагружено + 1;
		Исключение
			Сообщить("Пропущена одна запись — не удалось обработать: " + ОписаниеОшибки());
		КонецПопытки;
	КонецЦикла;

	Сообщить("Синхронизация завершена. Загружено/обновлено заметок: " + КоличествоЗагружено);
КонецПроцедуры

&НаКлиенте
Процедура Синхронизировать(Команда)
	СинхронизироватьНаСервере();
КонецПроцедуры
```

### Что делает каждый блок

- **Блок 1 (подключение)** — `HTTPСоединение`/`HTTPЗапрос` работают как `curl`.
  `Попытка/Исключение` ловит случай "сервер не запущен" — вместо краша
  показывает понятное сообщение.
- **Блок 2 (статус-код)** — если API вернул `400` или `500`, показываем
  текст ошибки из тела ответа вместо попытки распарсить его как заметки.
- **Блок 3 (JSON)** — `ПрочитатьЗначениеJSON` разбирает текст в массив
  структур. Если ответ — не массив (например, объект с ошибкой при неверном
  пути), сразу сообщаем об этом, не пытаясь перебрать как заметки.
- **Блок 4 (запись)** — `НайтиПоКоду` ищет существующую запись: нашёл —
  обновляет, не нашёл — создаёт. Обёрнуто в `Попытка`, чтобы одна битая
  запись не остановила обработку остальных.

## 2.5. Загрузить объекты в базу (если правишь XML напрямую, не через GUI)

```bash
wine 1cv8.exe DESIGNER /F"путь_к_базе" /LoadConfigFromFiles"путь_к_исходникам" /UpdateDBCfg
```

Если делаешь через обычный интерфейс Конфигуратора — просто Ctrl+S после
каждого изменения, этот шаг не нужен.

# ЧАСТЬ 3. Как всё это запустить вместе

1. Запустить Python-сервер (Часть 1, шаг 1.4), оставить окно открытым.
2. Проверить `curl http://127.0.0.1:8000/notes` — должен вернуться JSON.
3. Открыть 1С:Предприятие, войти (логин/пароль администратора базы).
4. Сервис → Синхронизация заметок.
5. Проверить поля: Сервер `127.0.0.1`, Порт `8000`, Путь `/notes`.
6. Нажать «Синхронизировать».
7. Открыть пункт меню «Заметки» — там появятся/обновятся записи.

## Как поменять данные

Отредактировать `/home/dissy/1cc/notes.json`, сохранить, снова нажать
«Синхронизировать» — сервер перезапускать не нужно, он читает файл заново
при каждом запросе.

# Частые ошибки

| Сообщение в 1С | Причина | Что делать |
|---|---|---|
| `Ошибка подключения к API: ...` | Python-сервер не запущен | Запустить `uvicorn` (Часть 1, шаг 1.4) |
| `API вернул 400 ...` | Некорректный запрос (например, битый параметр) | Проверить, что именно отправляется в запросе |
| `API вернул 500 ...` | На сервере ошибка (например, файл `notes.json` не найден) | Проверить, что файл данных существует по указанному пути |
| `Ожидался массив заметок, но API вернул другой формат` | Неверный путь (например, `/notes_service/notes` вместо `/notes`) | Проверить поле **Путь** в форме |
| `Данных нет — API вернул пустой список` | В `notes.json` пустой массив `[]` | Это не ошибка, просто нет данных |
| Список «Заметки» показывает старые данные | Список был открыт раньше и не обновился | Закрыть и заново открыть список «Заметки» |
| `ModuleNotFoundError: No module named 'uvicorn'` | Пакет не установлен в активном venv | `pip install fastapi uvicorn` (или `py -m pip install ...` на Windows) |
